Greptile 규칙 검증용 임시 문서
  ==============================================

  이 문서는 검증용 임시 파일이다. 병합하지 않는다.

  1. 표기 항목
  --------------------------------

  이관 대상 테이블의 컬럼 매핑을 확인한다.
  소스 데이터베이스 커넥션 정보를 입력하면 스키마 리스트가 표시된다.
  툴킷 설치 디렉토리 하위의 설정 파일을 편집한다.
  이관 작업 중 에러가 발생하면 리포트를 확인합니다.

  2. 보증성 표현
  --------------------------------

  CUBRID Migration Toolkit을 사용하면 데이터 손실 없이 완벽한 이관이 가능하다.

  3. 지적하면 안 되는 항목
  --------------------------------

  CUBRID Migration Toolkit은 마이그레이션 도구이다.
  소스 DBMS의 ``NUMBER`` 타입은 CUBRID의 ``NUMERIC`` 타입으로 매핑된다.
  "Table Column Mapping" 화면에서 대상 칼럼을 지정한다.
