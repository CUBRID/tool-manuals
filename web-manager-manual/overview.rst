버전
====

이 매뉴얼은 CUBRID Web Manager 베타 버전을 기준으로 작성한 것이며, 정식 버전에서는 일부 기능이 변경될 수 있다.

개요
====

CUBRID Web Manager는 데스크톱 전용이던 CUBRID Admin(CA)과 달리 웹 브라우저와 Electron 데스크톱 앱 두 가지 형태로 제공되며,
여러 CUBRID 호스트를 하나의 화면에서 관리할 수 있게 하는 것이 핵심 목표이다.

CA와 다른 점
============

* 데스크톱 전용이던 CA와 달리 **웹 브라우저** 에서 바로 접속 가능하다 (Electron 데스크톱 버전도 별도 제공된다).
* 여러 호스트를 **하나의 화면** 에서 그룹으로 묶어 관리할 수 있다.
* 그 외 데이터베이스/브로커/백업/HA 관련 화면과 조작 방식은 CA와 거의 동일하다. 이미 CA를 사용해본 경우 별도 설명 없이 대부분의 화면을 바로 사용할 수 있다.

공통 조작 규칙
==============

아래 규칙은 트리에 나오는 호스트/데이터베이스/브로커 화면 전반에 공통으로 적용된다.

* **한 번 클릭** 은 선택만 한다. **더블클릭** 은 로그인(또는 활성화)하고 대시보드/상태 탭을 연다.
* **그룹 행** 은 예외적으로 한 번 클릭에 선택과 펼치기/접기가 동시에 일어난다.
* **우클릭** 으로 컨텍스트 메뉴가 열리며, 바깥을 클릭해야 닫힌다 (Esc 키는 닫지 않는다).
* 백그라운드 작업(백업, 복사, 생성 등)이 끝나면 다른 작업 중이어도 완료 알림 모달이 갑자기 뜰 수 있다. 그냥 닫고 계속하면 된다.
* Broker Config / Cubrid Config 편집기는 저장 시 미리보기나 확인창 없이 실제 호스트 설정 파일에 즉시 반영된다. 되돌릴 수 없으니 주의한다.
