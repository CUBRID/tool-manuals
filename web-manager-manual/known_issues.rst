알려진 제약사항 / 문제
**************************

알아두면 좋은 제약사항
======================

* 호스트는 계정당 최대 400개까지 등록할 수 있다.
* HA로 구성된 데이터베이스는 일반 시작/중지 대신 별도 방식으로 동작하며, 생성/삭제는 HA 호스트에서 제한된다.
* 드물게 "Plan Dump"나 "Transaction Information" 조회 시 일시적으로 연결 실패가 발생할 수 있다. 재시도하면 대부분 해결된다.
* Copy Database 같은 무거운 작업 직후 몇 분간 해당 호스트 로그인이 일시적으로 지연될 수 있다.

현재 안 되는 것
================

.. warning::

    **20분 이상 걸리는 작업은 현재 정상 동작하지 않는다.** 대용량 데이터베이스의 백업/복원/언로드/로드, 대형 볼륨 생성 등
    오래 걸리는 작업을 실행할 때 이 시간을 넘기면 실패하거나 진행 상태를 알 수 없게 될 수 있다. 베타 기간에는 가능하면
    20분 이내에 끝날 규모로만 테스트한다.

이 문제는 현재 CMS와 통신하는 구조 자체의 한계이며, 추후 CMS 쪽을 수정해서 통신/작업 처리 구조를 바꾸는 방식으로 해결할 예정이다.
