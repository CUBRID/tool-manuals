******************
화면 구성 / 탭
******************

.. image:: /images/main-layout.png

호스트를 더블클릭하면 **Server Dashboard** 탭이 열린다. 데이터베이스를 더블클릭하면
(로그인 프로필이 없는 경우 먼저 Login Database 모달이 뜨고, 로그인 후 다시 더블클릭해야) **Database Dashboard** 탭이 열린다.

각 탭은 독립적으로 상태가 유지되며, 탭의 ``×`` 로 닫을 수 있다.

탭에 저장하지 않은 변경사항(예: Broker/Cubrid Config 편집 중)이 있는 채로 닫으면 **Discard Changes?** 확인 모달이 뜬다.
**Cancel** 을 누르면 닫지 않고 유지되고, **Discard** 를 누르면 변경사항을 버리고 닫힌다.
